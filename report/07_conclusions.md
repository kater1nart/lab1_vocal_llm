## 7. Выводы

**Ответ на исследовательский вопрос.** Открытые мультимодальные LLM размером 3–7B (Qwen2.5-VL-3B/7B, Gemma-3-4B) в режимах zero-shot и few-shot **не способны** определять тип фронт-вокала по изображению мел-спектрограммы. Лучшая конфигурация (Gemma-3-4B, few-shot) даёт Macro-F1 0,241 [0,195; 0,284] на сбалансированном тесте и 0,213 на полном тестовом срезе из 1 009 клипов, то есть уровень случайного угадывания (0,25). Обучаемая логистическая регрессия на статистиках мел/MFCC на том же тесте и тех же 10 секундах даёт 0,746.

**Проверка гипотез:**

| Гипотеза | Результат |
|---|---|
| H1: лучшая VLM few-shot даёт Macro-F1 ≥ 0,40 при невалидных < 5% | **Отвергнута.** Невалидных 0%, но Macro-F1 = 0,241 |
| H2: few-shot улучшает Macro-F1 относительно zero-shot | **Подтверждена** для всех трёх моделей (+0,043…+0,075), но абсолютный уровень остаётся случайным |
| H3: supervised-baseline сильнее VLM без дообучения | **Подтверждена**, разница +0,505 Macro-F1, доверительные интервалы не пересекаются |

Результат согласуется с литературой. В работе Dixit et al. (2024) успешной классификации спектрограмм достигали только крупные проприетарные VLM (GPT-4o) и только на звуках окружения с хорошо различимыми визуальными паттернами. MuChoMusic (2024) показывает, что мультимодальные модели склонны опираться на язык, а не на сигнал: мы наблюдаем то же самое в виде константных ответов.

**Решение о целесообразности использования в ВКР.** Использовать протестированные LLM как **основной** механизм разметки каталога по типу фронт-вокала **нецелесообразно**. Для ВКР принимается следующее решение:
1. Основной разметчик — обучаемая аудиомодель. Начальный baseline — LogReg мел/MFCC (0,70–0,75 Macro-F1). Дальнейшее развитие — предобученные аудио-энкодеры (musicnn, AST, MERT) с дообучением на MTAT, а также отделение вокала (source separation) перед классификацией.
2. LLM целесообразно рассматривать только во вспомогательных ролях: (а) аудио-LLM, работающие с сигналом напрямую (Qwen2-Audio и аналоги), — отдельный эксперимент; (б) текстовые LLM для нормализации метаданных и тегов каталога и для генерации описаний к поисковой выдаче на основе уже предсказанного типа вокала.
3. Требование к валидности структурированного ответа LLM выполняют (0–1,5% невалидных), поэтому их можно встраивать в пайплайн как компонент с JSON-интерфейсом.

**Ограничения работы:**
1. Проверены только малые открытые VLM (3–7B, 4-bit квантизация). Крупные проприетарные модели не проверены: Gemini API недоступен из РФ, для GigaChat-2-Max код подготовлен, но для получения ключа нужна авторизация через Сбер ID. Qwen2.5-VL-32B не загружена из-за скорости сети. Вывод не распространяется на модели масштаба GPT-4o/Gemini.
2. Проверен один вариант визуализации спектрограммы и одна инструкция. Dixit et al. показывают, что подбор визуализации и few-shot-примеров заметно влияет на качество. Систематический перебор не проводился.
3. Разметка MTAT слабая и шумная (пример: разные сегменты одного трека размечены как female и group), а метка относится ко всему 29-секундному клипу, тогда как модели видят первые 10 секунд.
4. Классы сцеплены с жанром (male–rock, group–opera). Часть качества baseline может объясняться распознаванием жанра, а не голоса. Это нужно проверять в ВКР на сбалансированной по жанрам выборке.
5. Каталог Magnatune не репрезентативен для коммерческого поп-каталога.
6. Стоимость API рассчитана по прайсам провайдеров, а не по фактическим счетам; для Qwen2.5-VL-3B взята верхняя оценка (цена 7B).
7. Каждая конфигурация запускалась один раз (temperature = 0), устойчивость к перефразированию инструкции не проверялась.

**Следующие шаги для ВКР:** fine-tuning аудио-энкодера на MTAT + MTG-Jamendo; проверка аудио-LLM на сыром сигнале; запуск GigaChat-2-Max по готовому коду; оценка на выборке, сбалансированной по жанрам.
