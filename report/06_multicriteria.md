## 6. Многокритериальная оценка: качество, надёжность, скорость, стоимость

**Выводы по критериям:**

1. **Качество.** Единственная конфигурация, пригодная для разметки, — обучаемый baseline (Macro-F1 0,746 на сбалансированном тесте, 0,696 на полном). Все LLM находятся на уровне случайного угадывания.
2. **Валидность ответа.** Здесь LLM работают хорошо (0–1,5% невалидных), но это не компенсирует отсутствие содержательного распознавания.
3. **Калибровка.** У baseline ECE 0,03–0,08: его вероятности можно использовать для порога «размечать автоматически / отправить на ручную проверку». Самооценка уверенности LLM для этого непригодна.
4. **Стоимость.** Через API разметка миллиона треков стоила бы $24–180. Это дёшево в абсолютных числах, но платить пришлось бы за качество ниже случайного. Few-shot удорожает запрос в 2,8–3,5 раза из-за дополнительных изображений: по фактическому счётчику токенов каждое изображение добавляет около 270 токенов у Gemma и около 140 у Qwen.
5. **Скорость.** Локальная VLM размечает миллион треков за 18–92 дня на одном устройстве, baseline — менее чем за сутки на одном ядре CPU.

Итоговый ранг по совокупности критериев: 1) LogReg мел/MFCC — лучший по всем критериям, кроме формата ответа (там ничья); 2) Gemma-3-4B few-shot — лучшая LLM, но не проходит порог качества.
