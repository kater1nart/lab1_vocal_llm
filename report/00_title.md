# Лабораторная работа 1. Большие языковые модели в предметной области ВКР

**Дисциплина:** Прикладные задачи машинного обучения

**Тема ВКР:** Разработка системы автоматической разметки музыкального каталога по типу фронт-вокала для задач поиска и рекомендаций

**Тема лабораторной работы:** Сравнение мультимодальных LLM для определения типа фронт-вокала по мел-спектрограмме

**Выполнил(а):** ____________________ (группа ________)

**Краткий итог.** Три открытые мультимодальные LLM (Qwen2.5-VL-3B, Qwen2.5-VL-7B, Gemma-3-4B) сравнены в режимах zero-shot и few-shot по единому протоколу на 200 клипах MagnaTagATune с разбиением по артистам. Лучшая LLM — Gemma-3-4B few-shot (Macro-F1 0,241, доля невалидных ответов 0%). Это уровень случайного угадывания, тогда как обучаемый baseline на мел/MFCC-признаках даёт 0,746. Вывод для ВКР: LLM по спектрограмме не подходят как основной разметчик, основой системы будет обучаемая аудиомодель.
